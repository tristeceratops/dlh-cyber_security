# Linux & Windows Security Cheat Sheet

## Linux

# System Hardening

### What is a CIS Benchmark?
- Security hardening guide published by the **Center for Internet Security (CIS)**.
- Organized into categories (Authentication, Network, Logging, Filesystem...).
- Each recommendation has:
  - Description
  - Rationale
  - Audit procedure
  - Remediation
- Apply recommendations with **professional judgment**, not blindly.

---

### SSH Hardening

Configuration file:

```text
/etc/ssh/sshd_config
```

Recommended settings:

```text
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
Protocol 2
AllowUsers admin analyst
ClientAliveInterval 300
ClientAliveCountMax 0
```

Restart SSH:

```bash
sudo systemctl restart sshd
```

---

### Kernel Hardening (sysctl)

Configuration:

```text
/etc/sysctl.conf
/etc/sysctl.d/*.conf
```

Common settings:

```text
net.ipv4.tcp_syncookies = 1
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.default.accept_redirects = 0
net.ipv4.ip_forward = 0
kernel.randomize_va_space = 2
fs.suid_dumpable = 0
```

Apply:

```bash
sudo sysctl -p
```

---

### Filesystem Hardening

Find SUID binaries:

```bash
find / -perm -4000
```

Find SGID binaries:

```bash
find / -perm -2000
```

Find world-writable files:

```bash
find / -perm -0002
```

Recommended mount options:

```text
noexec
nosuid
nodev
```

### Idempotent Bash Scripts

Rules:

- Safe to execute multiple times
- Check before modifying
- Never duplicate configuration
- Produce predictable results

Example:

```bash
grep -q "^PermitRootLogin no" file || echo "PermitRootLogin no" >> file
```

# Professional Judgment

### Apply or Skip CIS Controls

Apply when:

- Improves security
- No operational impact

Skip when:

- Breaks production
- Regulatory exception
- Legacy application

Always document:

- skipped control
- reason
- compensating control

---

### Security vs Operations

Balance:

- Confidentiality
- Integrity
- Availability

Never break critical services to achieve compliance.

# Windows

# Active Directory Security

### Active Directory Structure

```text
Forest
    ↓
Domain
    ↓
OU
    ↓
Users
Groups
Computers
```

Main components:

- Domain Controller (DC)
- Organizational Unit (OU)
- Groups
- GPO

---

### GPO Processing Order

```text
L
↓
S
↓
D
↓
OU
```

Meaning:

```text
Local
Site
Domain
Organizational Unit
```

Later policies override earlier ones.

Useful commands:

```powershell
gpresult /r
gpresult /h report.html
gpupdate /force
```

Enable auditing for:

### AppLocker

Modes:

- Audit
- Enforce

Rule types:

- Executable
- Script
- DLL
- MSI
- Packaged App

---

### SMB / RDP / Firewall / Service Accounts

Recommendations:

- Disable SMBv1
- Enable NLA for RDP
- Restrict RDP access
- Default deny Windows Firewall
- Use gMSA for service accounts
- Avoid local administrator accounts

# Acronyms

| Acronym | Meaning | Explanation |
|----------|---------|-------------|
| AD | Active Directory | Microsoft's centralized directory service for authentication, authorization, users, computers, and policies. |
| AppArmor | Application Armor | Linux Mandatory Access Control system that restricts application behavior using security profiles. |
| ASLR | Address Space Layout Randomization | Randomizes memory addresses to make memory corruption exploits more difficult. |
| CIS | Center for Internet Security | Organization publishing security benchmarks and best practices for hardening systems. |
| DC | Domain Controller | Server hosting Active Directory and authenticating domain users and computers. |
| GPO | Group Policy Object | Centralized collection of Windows configuration and security settings. |
| ICMP | Internet Control Message Protocol | Protocol used for network diagnostics and error reporting (e.g. `ping`). |
| IP | Internet Protocol | Protocol responsible for addressing and routing network traffic. |
| JSON | JavaScript Object Notation | Lightweight structured format used for exchanging and storing data. |
| LSDOU | Local → Site → Domain → Organizational Unit | Processing order of Windows Group Policies. |
| MAC | Mandatory Access Control | Security model where access is enforced by the operating system rather than users. |
| OU | Organizational Unit | Logical Active Directory container used to organize objects and apply GPOs. |
| PAM | Pluggable Authentication Modules | Linux framework used to configure authentication and password policies. |
| RDP | Remote Desktop Protocol | Microsoft protocol providing remote graphical access to Windows systems. |
| rsyslog | Rocket-fast System for Log Processing | Linux logging service used to collect, store, and forward logs. |
| SGID | Set Group ID | Special permission causing a program to run with the permissions of its group owner. |
| SMB | Server Message Block | Network protocol used for Windows file and printer sharing. |
| SSH | Secure Shell | Encrypted protocol used for secure remote administration. |
| SUID | Set User ID | Special permission causing a program to run with the permissions of its file owner. |
| Sysmon | System Monitor | Microsoft Sysinternals tool that generates detailed security telemetry for Windows endpoints. |
| sysctl | System Control | Linux utility used to view and modify kernel runtime parameters. |
